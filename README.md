# StageLog JP

StageLog JP is a small React and TypeScript scaffold for tracking Japan live events, ticket status, venue maps, and weather notes.

## Structure

- `public/venue-maps/` contains simplified SVG seating maps.
- `src/components/` contains reusable UI components.
- `src/pages/` contains app-level views.
- `src/data/` contains static venue metadata.
- `src/services/` contains event and weather helpers.
- `src/types/` contains shared TypeScript types.

## Next steps
